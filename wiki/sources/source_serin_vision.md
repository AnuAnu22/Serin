## Key contents

- Prime Directive: **causality, not performance** — state causes behavior, never a die roll.
- Affect as continuous physical system (energy/sass/engagement + mood vector);
  ConversationDynamicsEngine = Boltzmann (temperature) × Kuramoto (phase sync) ×
  Markowitz (attention portfolio); all parameters causally derived from observable state.
- Memory: Bayesian fact/belief layer over Qdrant+BM25 hybrid retrieval; every claim has
  evidence; PENDING→SUPPORTED→CONTESTED lifecycle ([[bayesian_beliefs]]).
- Personality: 5-factor traits drift slowly via reinforcement from interaction outcomes;
  never random-walked.
- Voice parity principle: voice input must carry the same guarantees as text input —
  same pipeline stages, memory, affect (drives the Phase-2 Rust gateway plan, issue #39).
- Anti-goals: no LLM-judged randomness dressed as state, no silent excepts, no dead code.
