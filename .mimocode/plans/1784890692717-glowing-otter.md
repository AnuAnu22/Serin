# Fix: Context Injection, Debug Wiring, and Facts/Beliefs Pipeline

## Root Causes Found

### Issue 1: Bot replies in 3rd person with no context
**Root cause:** `PromptAssemblyStage._build_messages()` computes conversation history (`collapsed`) but **never appends it** to the messages list.

**File:** `serin/d1_1_pipeline_flow/d2_1_flow_act/d3_1_act_runners/d4_3_prompt_assembly/d5_1_prompt_assembly.py`
**Line 228:** `return messages` — `collapsed` is discarded

The downstream `get_response_natural()` reads `current_messages[2:]` expecting history, but `ctx.built_messages` only has 2 items (system + context), so `current_messages[2:]` is empty.

### Issue 2: Debug prompts endpoint returns []
**Root cause:** `PromptAssemblyStage._store_prompt_debug()` only logs — it **never calls** `store_prompt_debug()` from the debug routes module. The store-write logic was lost during the Phase 5 refactoring.

**File:** `serin/d1_1_pipeline_flow/d2_1_flow_act/d3_1_act_runners/d4_3_prompt_assembly/d5_1_prompt_assembly.py`
**Line 252-257:** Method only does `logger.debug(...)` — no import or call to `store_prompt_debug()`

### Issue 3: Zero facts/beliefs
**Root cause A:** Pipeline `break` on `ctx.halt_reason` skips `MemoryWriteStage` (stage 9) when bot ignores/reacts. Since most messages get ignored, facts are never extracted for most interactions.

**File:** `serin/d1_1_pipeline_flow/d2_1_flow_act/d3_1_act_runners/d4_2_runners_pipeline.py`
**Lines 137-142:** `if ctx.halt_reason: break` — skips all stages including MemoryWriteStage

**Root cause B:** `DROP TABLE IF EXISTS facts` at line 128 of `d4_3_schema_store.py` wipes all facts on every bot restart.

## Fix Plan

### Fix 1: Append conversation history to messages
**File:** `serin/d1_1_pipeline_flow/d2_1_flow_act/d3_1_act_runners/d4_3_prompt_assembly/d5_1_prompt_assembly.py`
**Method:** `_build_messages()`
**Change:** After `collapsed = collapsed[-10:]`, add `messages.extend(collapsed)` before `return messages`.

### Fix 2: Restore debug store wiring
**File:** `serin/d1_1_pipeline_flow/d2_1_flow_act/d3_1_act_runners/d4_3_prompt_assembly/d5_1_prompt_assembly.py`
**Method:** `_store_prompt_debug()`
**Change:** Add lazy import of `store_prompt_debug` and construct the entry dict with user, channel, system_prompt, memories, relationship, beliefs, user_message, full_prompt fields.

### Fix 3: Run MemoryWriteStage even on halt
**File:** `serin/d1_1_pipeline_flow/d2_1_flow_act/d3_1_act_runners/d4_2_runners_pipeline.py`
**Method:** `process()`
**Change:** After the main loop, if `ctx.halt_reason` is set, run `MemoryWriteStage` (the last stage) anyway so facts are always extracted.

### Fix 4: Remove destructive DROP TABLE
**File:** `serin/d1_1_pipeline_flow/d2_4_flow_remember/d3_1_remember_core/d4_3_schema_store.py`
**Line 128:** Remove `cursor.execute("DROP TABLE IF EXISTS facts")`. Keep only the `CREATE TABLE IF NOT EXISTS facts` at line 130.
